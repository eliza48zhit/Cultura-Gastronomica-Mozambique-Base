🛠️ Especificaciones Técnicas del ADN de Mozambique
Este contrato documenta la química de las emulsiones y el aprovechamiento de recursos marinos:

Saturación Lipídica (uint256): Cuantifica la calidad y densidad de la leche de coco utilizada en platos como la Matapa. Un valor de 95 indica una base grasa óptima para la suspensión de alcaloides y la neutralización de fitotoxinas en hojas de yuca.

Índice Piri-Piri (uint256): Registra la intensidad de la capsaicina. Este parámetro mide la capacidad del plato para generar una respuesta térmica controlada sin comprometer las notas aromáticas del ajo y el limón.

Uso de Marisco Fresco (bool): Validador técnico de la cadena de suministro costera, esencial para la integridad proteica de las recetas de influencia afro-lusa.

Gobernanza: Funciones de darLike y darDislike para la interacción de la comunidad en Base.
